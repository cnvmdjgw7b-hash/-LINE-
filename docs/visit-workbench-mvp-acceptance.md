# 家電訪工作台｜測試介面驗收說明

更新：2026-11-10。此目錄使用既有主庫 `knowledge/scenario-review-1420/`，不建立第二份正式題庫。

## 已實作
- 手機優先的家訪／電訪表單與訪視對象、日期、資料來源。
- 分類勾選、當次事實、服務情況、風險、處置狀態分離。
- 規則式生成三種紀錄文字，禁止未確認處置被描述為已完成。
- 人工修訂與確認；本頁記憶體暫存50筆、同案同日同方式重複提醒。
- 四份 JSON 合計 1,420 筆的測試搜尋，資料ID與總數檢查；不將草案當正式規則。
- 安全限制：無正式帳號、資料庫或雲端儲存；僅可輸入模擬個案。

## 待驗收（不得宣稱完成）
- 使用真實測試環境進行瀏覽器／手機操作測試。
- 身分驗證、權限分級、傳輸加密、資料庫寫入、備份、操作軌跡。
- 對接正式個案資料庫及有效照顧計畫、核定服務。
- 1,420筆逐題語意去重、專業驗收、BA／GA／SC官方版本確認。
- AI模型生成與正式表單輸出；目前只有規則式草稿生成。

## 本機測試
從 repository 根目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/`。不要直接使用 file://，因瀏覽器可能阻擋 JSON 載入。

## 靜態部署
GitHub Pages 可部署根目錄 `index.html` 與 `knowledge/`；**僅限公開測試資料**，不得放真實個案個資。
